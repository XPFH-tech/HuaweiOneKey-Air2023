## 主要更新

- 基于 G2R1 新增本机阅读应用选择、搜索及显式启动入口。
- 支持选择番茄免费小说、华为阅读等实际安装且符合过滤条件的阅读软件；每应用及方向保存排版、手势与驻留时间。
- 默认靠边五点校准：横向12%/88%，纵向10%/90%；保留常规模式，分别保存校准。
- 保留横屏双页右下→左上翻页、单页模式、五种手势、实时文字提示、诊断及独立手势测试。
- 修复初次 G3 构建的 CheckBox 上下文类型错误。
- 独立 APK，不改动 U2。

## 验证

- GitHub Actions 构建成功，单元测试、APK 签名及包名检查通过。
- 维护者反馈 G3 真机使用成功；具体应用逐项兼容性、边缘校准准确率、长期耗电尚未完整验证。

## 下载与安装

- [构建记录](https://github.com/XPFH-tech/HuaweiOneKey-Air2023/actions/runs/45903064405)
- [下载 G3 ZIP](https://github.com/XPFH-tech/HuaweiOneKey-Air2023/actions/runs/45903064405/artifacts/15155739520)（保留7天，可能需登录）
- [完整使用说明](../../gazeg3/README.md)

停用旧眼动版本后安装 G3，授权相机和无障碍，选择阅读应用、排版及手势，重新校准并启用。G3 不迁移旧版校准；不支持分屏/小窗。系统手势完成不等于实际翻页。浏览书架时建议暂停，退出阅读后停止相机。
