# Island I3
Based on user-confirmed I2 (9c770e68), same status-bar clock host and geometry guards, no new windows or touch hooks. Local playback metadata title/artist and supplied bitmap only from selected playing media session. Sanitizes and ellipsizes text, refuses oversized/recycled/hardware bitmaps, scales to max 128px, no URI/network fetch, file persistence or private title logging. Clears references on hide/lock/detach (session object retains its own metadata). Rich capsule falls back to compact generic if collision. Media volume read via existing AudioManager on I2 polling (idle 2s, active 1s); change indicator ~2.5s, no audio writes or native volume panel suppression. AudioDeviceCallback observes new Bluetooth audio outputs (A2DP/SCO/hearing aid/BLE), initial snapshot not counted, 3.5s transient, not actual route confirmation or generic Bluetooth pairing. Charge 5s > Bluetooth > volume > media. Keep all other modules unchanged, disable I1/I2, enable I3 SystemUI only, backup before soft restart. No click/expand, media transport control, configurable location/width, timers, independent switches yet. Compile and real device rendering, metadata, audio-device callback behavior, privacy on lock and power impact require verification.
