# Island I2
I1 device log: I1_HOST_READY width=2800 height=180 media=true; charging event received; I1_SKIP_GEOMETRY. I2 adapts the bounded status-bar root to 256dp maximum, anchors capsule Y to HwStatusBarClock text baseline and font metrics, bounds it within root and top 96dp. Retains exact firmware, status bar type, display and screen/keyguard guards, no overlays outside root, no touch/notification access, no native capsule hiding. Collision guard remains conservative; logs only blocking view class, resource entry name and geometry, no text. Adds session count and playback-source transitions, queries AudioManager.isMusicActive as generic media fallback when no active playing session. Checks every 2s while unlocked visible and idle, every 1s when active, stops when screen is off; can retry during screen-on/keyguard transition. Audio state can include video or other media, not necessarily music. No title, album, actions, config, timers, Bluetooth. Actual target status bar geometry and visibility are still untested. Install new separate package, disable I1, enable I2 SystemUI only; retain other modules. Back up and manually soft restart. Check I2_GEOMETRY_OK, I2_MEDIA_STATE SESSION/AUDIO, I2_SHOWN CHARGE/MEDIA; if blocked, provide diagnostic class and bounds.
