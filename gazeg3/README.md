# Air2023 眼动阅读 G3

**1.3-G3 · MatePad Air 2023 横屏双页适配版**

基于 [Raabo/GazeUp](https://github.com/Raabo/GazeUp) 与 [Deep-SkyLabs/gaze-control](https://github.com/Deep-SkyLabs/gaze-control) 的技术思路，针对 MatePad Air 2023 开发的独立眼动翻页工具。使用普通前置摄像头、本地人脸关键点推理及 Android 无障碍手势，无需 Root，不移植华为专有眼动算法。

## 主要功能

- 横屏双页/双栏（左至右）：读完右页底部，再看向左上并停留，触发下一页；左页底部不会单独触发。
- 单页或纵向滚动：注视底部后抬眼，触发所设手势。
- 三点/五点校准，支持常规及靠边校准，各方向独立保存。
- 自动发现本机阅读软件，名称或包名搜索；可显示其他符合过滤条件的可启动应用。
- 每款应用及屏幕方向独立保存阅读排版、手势、驻留时间（350–1550ms）。
- 支持左滑、右滑、上滑、下滑、右侧点击；一键开启眼动并启动所选应用，也可仅打开应用。
- 底部非触摸文字提示，眼动触发与手势完成计数、一次性手势测试及复制诊断。
- 丢脸/闭眼保护、冷却、目标全屏窗口检查；锁屏、方向变化、严重热状态或运行45分钟自动停止。

## 使用方式

1. 停止旧 G1/G2/G2R1 的相机和无障碍服务。G3 是独立包名，旧校准不自动迁移。
2. 打开 G3，启用无障碍并授权摄像头，启动前置摄像头。
3. 选择已安装的阅读软件。根据阅读软件实际排版选择单页/滚动或横屏双页，并选择对应翻页手势。
4. 勾选靠边校准（默认），完成当前方向和排版的三点或五点校准。建议平板固定、脸距30–60cm，光线充足。
5. 初次使用某款阅读软件可先进入正文，然后返回 G3 启动独立手势测试，在20秒内切回正文，核对实际是否翻页。
6. 点击「启用眼动翻页并打开所选阅读软件」，进入书籍正文。单页看底部再抬眼；双页看右下再看左上。
7. 浏览书架、更换书籍或结束阅读时暂停/停止，可从通知栏停止相机。

建议尝试微信读书、番茄免费小说、华为阅读、起点读书、阅读 Legado、掌阅、多看、Kindle 等。以本机扫描结果为准；名单支持识别不等于所有软件已经验证可翻页。未找到时尝试搜索或勾选「显示其他可启动应用」。核心系统应用及部分敏感工具被过滤。

### 校准位置

坐标以校准内容区域宽高的百分比计算，而非物理屏幕绝对坐标。

| 模式 | 左 / 右 | 上 / 下 |
| --- | --- | --- |
| 常规双页 | 25% / 75% | 16% / 84% |
| 靠边双页（默认） | 12% / 88% | 10% / 90% |
| 靠边单页 | 中央50% | 10% / 90% |

双页按中央、左下、右下、左上、右上顺序校准；单页按中央、底部、顶部校准。靠边模式同时调整触发比例，不要求始终盯着边缘圆点。实际提升幅度尚未量化。

### 状态提示与排障

| 提示 | 含义 |
| --- | --- |
| 阅读中 · 等待右页底部 | 正在识别视线 |
| 检测到右页底部 · 请停留 | 底部信号满足初步条件 |
| 右页已读完 · 看向左上 | 已进入待翻页状态 |
| 检测到左上 · 正在确认 | 正在满足抬眼驻留条件 |
| 已触发 · 正在发送翻页手势… | 眼动触发 |
| 手势已完成 · 第 N 次 | Android 手势回调完成，不等于书页确实翻动 |

无反应时先做独立手势测试，再检查校准、目标包名、全屏状态及相机画面。应用内可复制 G3 诊断报告；ADB 可使用 `adb logcat -s Air2023GazeG3`。不必 Root。

## 技术与隐私

CameraX 1.4.1 + MediaPipe Tasks Vision 0.10.14，Kotlin 2.0.21。按画面比例和眼角方向计算虹膜纵横偏移、眼睑开度（EAR），结合个体校准、驻留及状态机，交由无障碍服务发送手势。相机帧本地处理，不保存影像，应用未声明网络权限。仅保存校准和配置；诊断报告含包名及运行状态，分享前请检查。无障碍用于活动窗口、包名、窗口边界检查与手势派发，不遍历正文内容。

## 构建

JDK17、Gradle8.9、Android SDK35。CI 从固定 GazeUp 提交复制 Face Landmarker 模型至 app/src/main/assets，并打包来源声明和许可证。模型准备完成后：

```bash
gradle -p gazeg3 --no-daemon :app:testDebugUnitTest :app:assembleDebug
```

完整流程见 [G3 构建工作流](../.github/workflows/gazeg3.yml)。

## 验证与限制

2026-11-27：G2R1 与 G3 获得项目维护者真机成功反馈；G3 修复后的云端构建成功。尚无逐应用测试矩阵、识别率对照数据或长期续航测试。不支持小窗/分屏，不能可靠区分书架与正文，切换方向须重新启动相机并选择对应校准。弱光、反光、头部移动可能降低识别质量。非官方华为眼动翻页，无红外专用硬件依赖，不承诺与官方功能等效。
