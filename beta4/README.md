# Air2023 0.4 beta
Separate package dev.air2023.onekeybeta4, so keep 0.3 for rollback. Three previously tested features are enabled in initial configuration; nine added experiments are off. No automatic root commands, system restart, old property flags or system_server hook. Open the app before enabling scopes. Configuration uses XSharedPreferences with xposedsharedprefs metadata; Vector compatibility is unverified. If CONFIG_READ_FAILED appears no hooks run; keep using 0.3. Scope remains an independent gate.
New features: app details, 7x5/8x5, layout dedupe, dock 11/8, portrait dock alignment (not forced portrait), drawer suggestions, icon text, card titles and blur with radius. Blur requires API 31+. Layout edits can persist, back up first. Safety mode applies after target process reload, does not reverse prior changes. CC volume deferred: third-party smali needs a separate review and isolated build. No theme or installer bypass. Upstream license included. Ephemeral signing key.
