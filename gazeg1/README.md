# Air2023 眼动翻页 G1
独立实验 APK，DBY2-W00 / API31 / arm64-v8a。前置相机 CameraX + MediaPipe，横竖屏分方向校准，底部眼睑开度驻留后抬眼触发下一页。约10fps，单人脸、丢脸/闭眼清除状态、真实单调时钟、冷却与白名单全屏检查。仅一个用户选择的阅读包名。无需 Root 或 Vector，无网络权限，不存储影像；仅保存校准和配置。无障碍只检查当前应用及窗口，不遍历内容。前台相机有停止通知，锁屏、方向变化、严重热状态或45分钟结束。部分 ROM 可能限制相机前台服务，无权限绕过。开启无障碍、在本应用启动相机，三点校准，再启用翻页并手动进入目标阅读应用。适配点击/四向滑动，不支持小窗/分屏。首版没有跨应用提示胶囊、头部/手势识别、ONNX，尚未真机验证，误触与续航待测。U2 不变。详细署名见 NOTICE.md。
