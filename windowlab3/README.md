# WindowLab D3 — custom window limit
Exact DBY2-W00 / 4.2.0.252(C00E100R3P5). D2R1 user confirmed four simultaneously visible windows after soft restart, via /system/bin/magisk resetprop. D3 exposes 2–64, maximum shortcut 64 (upstream configuration, not proven hardware max), previous value undo and explicit restore to absent (D1 stock baseline). Checks readback and system_server PID/boot ID; not proof of actual visible window count. On each write requires current property and process identity match preceding inspection; refuses unknown/out-of-range property state. Records pending change before write, reconciles on next inspect when possible. No automatic reboot, no persistent property, no framework hook, no system partition write, no background service. Existing 4 is supported as an explicit migration; do not use old D2R1 restore after D3 changes. Keep v0.4. CI ephemeral signing uses separate package. Higher limits untested, actual many windows may cause memory pressure/crash; save work and test incrementally. Stock restore may require framework reinitialization. D3 is independent, not combined v0.5 yet.
