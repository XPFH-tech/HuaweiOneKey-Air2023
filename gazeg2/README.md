# G2 横屏阅读适配与诊断
独立 APK，目标 DBY2-W00/API31。新增单页三点和双页五点校准；双页左→右，右页底部驻留后看左上翻页。按当前活动根节点与对应全屏应用窗口校验，允许无关低层窗口，不允许分屏、输入法和其他活动应用窗口。提供一次性手势测试（20秒内进入指定应用，无需校准但相机服务须运行）、非触摸状态提示和日志复制。系统手势完成不等于阅读应用确实翻页。G1 用户未能翻页，原因未确认；G2 实机待测。无Root、无Vector、无网络、不保存影像。U2不变。测试时停用G1无障碍并停止其相机。

## G2R1
阅读页默认显示底部非触摸文字提示，区分底部检测、抬眼确认、眼动触发、正在发送、系统手势完成、取消或拒绝；结果保留约2.4秒，手势测试也显示。触发计数与手势完成计数分别记录。仅目标应用活动时显示；若系统无法确认目标根节点，返回控制页查诊断，不在其他应用浮显。手势完成不等于已实际翻页。可关闭提示。G2R1 与 G2 同包名，独立CI签名可能需要卸载G2后安装；U2不变。
