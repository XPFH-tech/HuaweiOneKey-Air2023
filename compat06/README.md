# Air2023 CompatLab C1
v0.6 C1 independent experimental APK for exact DBY2-W00 4.2.0.252(C00E100R3P5). Preserve v0.4 and D3 (D3 64 limit user-confirmed, actual maximum untested). D1 confirmed XML paths and different su/system_server mount namespaces. C1 uses nsenter only if needed, requires actual current system_server namespace, requires all detected zygote and running systemmanager (clone) share it before writing, refuses foreign exact mount and changed baseline. Read-only preview merges missing third-party user-0 package names into original UTF-8 XML without rewriting original bytes; existing entries preserved, own apps and standard Magisk excluded. Parallel uses upstream attributes, default_setting=false; existing disabled entries not overwritten. Optional explicit apply writes generated file to root-owned /data/adb/air2023_compat06/<boot>/<feature>, labels it like original and temporarily bind-mounts it, verifies file inode, hash, namespace. Restore only own mount; no lazy unmount, no partition write, no forced process stop/reboot or auto start. No permanent boot scripts. Mount may not survive soft reboot; system caches may not refresh; visibility to future processes not proven. App clone UI/creation and actual parallel layout not verified. Restore does not remove cloned apps or their data. If transaction interrupted use status and restore; may refuse if namespace changes, full reboot normally drops bind mounts but loses temporary root. Do not attempt manually removing unknown mounts. Reports contain package names; user explicitly shares. First test one non-critical app, clone first; no promise that all apps support cloning or parallel layout. No raw firmware files committed.
