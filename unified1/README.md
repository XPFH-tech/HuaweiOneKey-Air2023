# Air2023 1.0-U1 integration pilot
Target DBY2-W00 4.2.0.252(C00E100R3P5), SDK31. First integration stage: reuses v0.4 base, V1 volume, I4 island, D3 tool in one APK, with one dispatcher and strictly limited three scopes. No system_server or clone hook in U1; C4R1 remains enabled and unchanged. Home can open existing C4R1; no new root write or clone sync runs automatically. Independent three master switches default off. Shared prefs are initialized under new package, no old private preferences copied: manually match v0.4 and I4 settings. Enable U1 in Vector (Settings, Huawei launcher, SystemUI only), force-stop U1 app and reopen, press publish (forces real preference writes), set matching subfeature options. Disable old modules for the specific groups you enable in U1; if testing just volume/island keep old v0.4 enabled until U1 base is tested. Never enable duplicates. Back up important data and manually soft restart. Read U1_CONFIG_OK by process and old feature logs. U1 no auto soft reboot. D3 uses same property operations but new independent local undo history; do not overwrite a good current property just to test, begin with read-only inspection. No automatic migration of D3 undo or clone data. Keep existing packages for rollback. CI uses ephemeral test signing, no stable update key yet. No added timer, stopwatch, parallel view or other upstream unverified features. User confirmed earlier modules, U1 combined behavior and config not verified on target yet.
