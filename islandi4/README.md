# Island I4
Based on user-confirmed I3. Uses v0.4-style XSharedPreferences read-only snapshot with schema and required boolean guards. Open app to initialize before scope enable. Configuration unavailable or disabled: no hooks. Seven switches, offset +/-120dp, width 80–125%, save then reinitialize SystemUI. Retains I3 battery/media/metadata/volume/BT display and collision/keyguard checks. Adds a single bounded transparent clickable View only to compatible FrameLayout status-bar roots and only for a visible media pill with standard playing session. No global touch hook, no interception outside target; swipes starting on target may be affected. If unsupported root, display-only. PopupWindow uses existing view token, no privileged window types or hidden flags, may be denied/clipped by OEM; closes on mode/geometry/lock/detach/session change. Buttons dispatch only advertised MediaSession actions after direct user click and rechecking current session; no automatic media actions. Paused session retained only while popup open. No notification access, URI fetch or native warning suppression. Timer/stopwatch deferred, no live setting reload, no vertical adjustment. User tests compile and actual interaction. Disable I3 before enabling I4, retain I3 for rollback; backup before manual soft restart. Other modules unchanged.
