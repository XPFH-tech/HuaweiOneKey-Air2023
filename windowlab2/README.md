# WindowLab D2
Standalone experimental APK for exact DBY2-W00 build 4.2.0.252(C00E100R3P5), no Xposed scope, no automatic restart. D1 shows 3 freeform tasks but only 2 visible. Firmware DEX inspection: HwMultiWindowManager.<clinit> reads hw_mc.freeform.max_num with default 2 (normal non-IVI branch); onSystemReady calls calcDefaultFreeFormNum, caches sForegroundFreeFormStack; allowedForegroundFreeForms returns cached value for ordinary display. limitForegroundFreeformStackCountInner and setFreeFromStackInvisible use that limit. Overflow path clears always-on-top and/or moves task down. The first experiment uses original property mechanism, not a framework hook. Property is written only when absent; no persistent flag. User must choose whether to soft restart after saving work; compare system_server PID and boot_id and verify property still 4. Soft reboot may not retain root or property. Restore deletes only current 4 if the APK recorded successful application. If property was changed but the process died before recording it, use explicit manual root recovery after checking ownership (resetprop -d hw_mc.freeform.max_num); current cached value may require subsequent system server initialization. If property disappears on restart the app's local recorded flag can remain; clear app data ONLY after confirming property absent. Test 3 visible tasks, not just 3 running tasks. No claim of successful unlock until device test. v0.4 remains unchanged. No uploaded firmware binaries committed.
